# DNS Resolver Visualizer

## 1. Project Description

DNS Resolver Visualizer is a web-based project designed to demonstrate DNS resolution and visualize the process through a dashboard.

The project uses Python for its backend logic and HTML, CSS, and JavaScript for the web interface.

## 2. Features

- Web-based DNS Resolver Visualizer dashboard
- DNS resolution logic implemented in Python
- Interactive interface for entering and resolving domains
- Visualization of results through the dashboard
- Separate frontend assets and backend logic
